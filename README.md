# MEMEGIFT — starter project

Стартовый шаблон Telegram Mini App + Telegram-бота для Windows.

## Что уже есть
- React + Vite Mini App: вкладки «Кейсы», «Апгрейд», «Игры», «Профиль».
- Демонстрационный виртуальный баланс (сбрасывается при перезагрузке страницы).
- Подключение Telegram Web Apps SDK и отображение имени пользователя Telegram, если Mini App открыта внутри Telegram.
- Базовый Telegram-бот на Telegraf с командой `/start`.
- Health endpoint: `/health`.

## Важно
Это именно стартовый интерфейс, а не готовая игровая/платёжная система. Баланс пока демонстрационный; серверная база данных, реальные предметы, честная серверная логика случайных выпадений, платежи, админ-панель и поддержка ещё не реализованы. Не принимайте реальные деньги и не обещайте реальные призы на этой демо-версии.

## Установка на Windows
1. Установите Node.js LTS с https://nodejs.org/.
2. Распакуйте архив и откройте папку `MEMEGIFT_starter`.
3. В адресной строке Проводника напишите `cmd` и нажмите Enter.
4. Выполните:
   ```bash
   npm install
   ```
5. Запустите Mini App локально:
   ```bash
   npm run dev
   ```
   Vite покажет локальный адрес, обычно http://localhost:5173.
6. Чтобы собрать сайт:
   ```bash
   npm run build
   ```

## Настройка бота
1. Скопируйте `.env.example` в новый файл `.env`.
2. В `.env` укажите новый токен, полученный у BotFather, в `BOT_TOKEN`.
3. В `WEB_APP_URL` укажите HTTPS-адрес опубликованного Mini App.
4. Запустите бота отдельным окном терминала:
   ```bash
   npm run server
   ```

**Безопасность:** никогда не отправляйте токен в чат и не загружайте `.env` в GitHub. Файл `.env` уже добавлен в `.gitignore`. Если токен раскрывался, сначала отзовите его через BotFather и используйте новый.

## GitHub
Перед публикацией убедитесь, что в репозитории нет `.env`. Загружайте исходники, `package.json`, `README.md` и `.env.example`; папки `node_modules` и `dist` не нужны.
